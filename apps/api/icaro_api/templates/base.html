Glossary

Apogee
The highest point your rocket reaches during flight, measured in metres above sea level.
Stability margin
A measure of how stable a rocket is in flight, expressed in calibres (rocket diameters). A margin of 1–2 calibres is generally considered stable.
Atmosphere model
The mathematical description of the atmosphere used in the simulation. "Forecast" uses real weather data for your date; "Standard atmosphere" uses the international standard atmosphere when real data is unavailable.
Uncertainty (std)
Standard deviation for a simulation parameter. Larger values produce a wider spread of possible outcomes in dispersion analysis.
Relative std
Uncertainty expressed as a fraction of the nominal value (e.g. 0.05 = ±5%).
Absolute std
Uncertainty expressed in the same unit as the parameter (e.g. ±2° for heading).
Rail departure velocity
The speed of the rocket when it leaves the launch rail. It must be high enough for the fins to provide stable flight.
