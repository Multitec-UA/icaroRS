# web-interface-guidelines — fix apps/web against Vercel Web Interface Guidelines

Objective: audit `apps/web` with the `web-design-guidelines` skill and fix the findings. Branch `fix/web-interface-guidelines` (from `main`), delivery `single-pr` (user asked for one PR), runner `npm test` (vitest) + `npm run lint` + `npm run i18n:check` in `apps/web`.
Rules source: https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md (fetched 2026-10-24, scratch copy `wig.md`).

## Specs

- S1 Shared primitives (`components/ui.tsx`, `lib/styles.ts`, `components/motion.tsx`): `Button` gets `focus-visible:ring-*` and no `transition-all`; `inputBase`/`selectClass` use `focus-visible` and explicit transition properties, `<option>` gets explicit `background-color`/`color`; `Field` wires `aria-invalid` + `aria-describedby` (hint/error ids) and the error has `role="alert"`; `Callout` gets `role="alert"` for `tone="error"` and `aria-live="polite"` otherwise; `Spinner` accepts being hidden (`aria-hidden`) when visible text sits next to it; `Accordion` summary and `InfoTip` get focus-visible styles, `InfoTip` becomes a `<button type="button">`; `CountUp` renders the final value under reduced motion after hydration; `common.loading` ends with `…`.
- S2 App shell: `app/layout.tsx` exports `viewport` with `themeColor: "#050505"` and `colorScheme: "dark"`; skip link + `<main id="main">` in `AuthGate`'s authed branch; `globals.css` adds `touch-action: manipulation`, `-webkit-tap-highlight-color: transparent`, `@media (pointer: fine) { html { overscroll-behavior: none } }`, `scroll-padding-top`, `env(safe-area-inset-*)` padding on body; `AppNav` items and `ResultsActions`/`results error` navigation become `<Link>` (keeping the wizard `reset()` on click); `AccountMenu`, `LanguageSwitch`, `GlobalErrorContent`, `NotFoundContent` get focus-visible styles; `LanguageSwitch` buttons get `lang` + `translate="no"`; `GlobalErrorContent` title is an `<h1>`; h1/h2 get `text-balance`; identifiers (email, org id, run id, created_by) get `translate="no"`; `global-error.tsx` resolves the cookie locale in an effect.
- S3 Wizard + map: `Stepper` is a `<nav aria-label>` with `aria-current="step"`, hidden glyphs, focus-visible, explicit transitions; inputs get `name`, `autoComplete="off"`, `inputMode`, `spellCheck={false}` where relevant; first invalid field receives focus after a failed validate; async status text sits in `aria-live="polite"`; `RocketStep` dropzone becomes keyboard-operable (`<label htmlFor>` + `sr-only` input, focus-visible, hidden glyphs, `break-words` on names); `AdvancedStep` table inputs/selects get `aria-label`s, radio group gets `fieldset`/`legend` and `has-[:focus-visible]` ring, `tabular-nums` on numeric columns, an error inside a collapsed `<details>` opens it; `ReviewStep` formats numbers with `Intl.NumberFormat(locale)` and `&nbsp;` before units, long values wrap; `WizardProvider` warns with `beforeunload` while the draft is dirty and no run exists; `WizardShell` moves focus to the new step heading; `MapInner` container gets an accessible name, marker `title`, hidden pin SVG; `SitePicker` input gets a label/`type="search"`/`name`/`autoComplete="off"`/`spellCheck={false}`, results get `aria-live` count, an empty state, Escape to close, stable keys, `max-h` + `overflow-y-auto` + `overscroll-contain`, focus-visible, debounce cleared on unmount.
- S4 Results/charts/lists: `PlotCard` img gets `width`/`height`/`loading="lazy"` and a wrapping caption; `ResultsContentServer` back link gets focus-visible + explicit transition, run id `translate="no"`, warnings `break-words`, row labels `<th scope="row">`, stagger capped; `SeriesChart` metric labels/axis go through `t()`, tooltip via `Intl.NumberFormat(locale)`, `aria-pressed` on metric toggles, focus-visible, `animation: false` under reduced motion, canvas container `role="img"` + `aria-label`; `Trajectory3D` pauses `autoRotate` with the Pause button and under reduced motion, starts paused under reduced motion, rAF loop only while playing, percent via `Intl.NumberFormat`, Canvas wrapper `role="img"` + `aria-label`; `HistoryCard`/`RocketCard` use `Intl.DateTimeFormat`/`Intl.NumberFormat` with the app locale and a fixed `timeZone: "UTC"` (hydration-safe), `truncate`/`break-words`/`min-w-0` on user content, `aria-live` on inline errors, `translate="no"` on identifiers, Reveal stagger capped at 10.
- S5 i18n: every new visible string and aria label goes through `messages/en.json` + `messages/es.json`; `npm run i18n:types` regenerates `messages/keys.d.ts`; `npm run i18n:check`, `npm run lint` and `npm test` pass; existing tests updated only where the DOM contract changed on purpose.
- Deferred (documented in the PR, not in scope): wizard step in the URL (the step depends on an in-memory uploaded file that a URL cannot restore), list virtualization (lists are per-user and small), keyboard orbit for the 3D canvas (needs custom controls), full ARIA combobox for `SitePicker`, copy rewrites of existing catalog strings (Title Case / second person) beyond the strings touched above.
