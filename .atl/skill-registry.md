## Compact Rules (auto-resolved into sub-agent prompts)

### Python / code changes (rocketpy/**, tests/**)
- Format with **Ruff** (`ruff format`, line-length 88, double quotes) — matches Black style.
- Lint with **Ruff** (`ruff check`, selects E4/E7/E9/F; F401 ignored) AND **Pylint** (`pylint rocketpy/ tests/ docs/`).
- Docstrings: **NumPy** convention.
- Scientific precision: do NOT introduce approximations or hardcoded physical constants without rigorous justification.
- Performance-sensitive: core calculations run thousands of times in Monte Carlo — keep them efficient.
- Preserve the public API flow: `Environment` → `Motor` → `Rocket` → `Flight`.

### Testing
- Runner: `pytest`. Layers: `tests/unit`, `tests/integration`, `tests/acceptance`, plus doctests (`pytest rocketpy --doctest-modules`).
- Coverage: `pytest --cov=rocketpy`.
- Fixtures live under `tests/fixtures/*` and are registered in `tests/conftest.py`.

### PR / Issue workflow
- Use **branch-pr** for PRs and **issue-creation** for issues (issue-first enforcement).
