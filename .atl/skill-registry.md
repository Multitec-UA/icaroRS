## Compact Rules (auto-resolved into sub-agent prompts)

### Python / RocketPy core (`rocketpy/**`, `tests/**`, `data/**`)
- Python target: **3.10+** (project requires-python `>=3.10`).
- Format with **Ruff** (`ruff format`, line-length 88, double quotes) — matches Black style.
- Lint with **Ruff** (`ruff check`, selects E4/E7/E9/F; F401 ignored on `__init__.py`) AND **Pylint** (`pylint rocketpy/ tests/ docs/`).
- Docstrings: **NumPy** convention.
- Scientific precision: do NOT introduce approximations or hardcoded physical constants without rigorous justification.
- Performance-sensitive: core calculations run thousands of times in Monte Carlo — keep them efficient.
- Preserve the public API flow: `Environment` → `Motor` → `Rocket` → `Flight`.

### Python / RocketSerializer (`packages/RocketSerializer/rocketserializer/**`, `packages/RocketSerializer/tests/**`)
- Python target: **3.8–3.12** (subpackage supports a wider range than the core).
- Format with **Black** (line-length 88) — pyproject configures Black + isort (Black profile).
- Lint with **Pylint** (`pylint rocketserializer/`).
- Dev deps: `pytest==7.4.0`, `pytest-coverage`, `mypy`, `flake8`, `isort`.
- **Gotcha**: `rocketserializer/__init__.py` does `from .ork_extractor import ork_extractor`, which **rebinds the package attribute from module to function**. To `mock.patch` attributes on the module, retrieve it via `sys.modules["rocketserializer.ork_extractor"]` — `import as` and dotted-string paths return the function and fail with AttributeError. (See engram observation `rocketserializer/test-patching-gotcha`.)

### Testing
- Runner: **pytest** (both subprojects).
- **Core** layers: `tests/unit`, `tests/integration`, `tests/acceptance`, plus doctests (`pytest rocketpy --doctest-modules`).
- **Serializer** layers: `tests/unit`, `tests/acceptance`.
- **Serializer acceptance is JVM-bound**: needs Java (21 LTS used in CI) + `packages/RocketSerializer/OpenRocket-23.09.jar` (working-dir relative).
- Coverage: `pytest --cov=rocketpy` (core), `pytest --cov` (serializer).
- Fixtures: core under `tests/fixtures/*` and `tests/conftest.py`; serializer under `tests/conftest.py`.

### CI (GitHub Actions)
- Two workflows live at `.github/workflows/`:
  - `test_pytest.yaml` — RocketPy core, path-scoped to `rocketpy/**`/`tests/**`/`data/**`. Matrix: ubuntu × py3.10/3.12.
  - `test-pytest-serializer.yaml` — RocketSerializer, path-scoped to `packages/RocketSerializer/**`. Sets up Java 21 + checks jar presence. Matrix: ubuntu × py3.10/3.12.
